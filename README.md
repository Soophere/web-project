# Nashaat Gym Website

COMP3700 Project Part II. A static website for the Nashaat gym in Al Ansab, Muscat.
Only HTML and CSS, no JavaScript.

Live website: https://soophere.github.io/web-project/
GitHub: https://github.com/hazza-albadi/web-project

## Pages

- index.html - home page, links to all the other pages
- about.html - about us, the facilities and the email link
- contact.html - contact details, map and the contact form (sends by email)
- plans.html - membership plans table and the registration form
- classes.html - class timetable and the class booking form
- trainers.html - our trainers and the personal training times
- workout.html - exercise library and the beginner plan
- dashboard.html - login, log workout form and workout history

## What is on the website

- the same header with the logo, menu and footer on every page
- five tables (plans, timetable, trainers, workout plan, workout history)
- five forms: registration, class booking, login, log workout, contact
- the contact form sends to our email, the other forms send to httpbin.org/get
- phone design with a media query

## Files

- css/style.css - the style sheet used by all the pages
- images/ - logo, banner, trainer and exercise pictures
- docs/part1-proposal.pdf - our Part I report

## Built with

HTML5 and CSS3. The style is in the external style sheet, every page also has a
small internal style block, and some elements use inline styles.
